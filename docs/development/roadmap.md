# 路线图

日期：2026-06-03

## 阶段 0：调研与规划

状态：进行中

- 对比可用开源项目。
- 确定显示输出硬件策略。
- 定义初始架构。
- 定义组件契约草案。
- 建立文档和更新记录规范。
- 记录当前真实 HDMI 长条屏信息。
- 增加 framebuffer 颜色/色条测试工具。
- 增加 DRM/KMS 颜色/色条测试工具，并确认真实 scanout 路径可用。
- 初步定义插件式扩展模型。

## 阶段 1：最小可运行预览

- 使用 DRM/KMS 颜色测试确认可控屏。
- 搭建 React + TypeScript 前端。
- 增加本地指标服务。
- 增加 WebSocket 数据总线。
- 增加一个面向当前 `3840x1100` 屏幕的示例布局。
- 保留 800x480、1024x600 等常见小屏示例布局。
- 增加时钟、CPU、内存、磁盘、网络核心组件。
- 增加预览/mock 数据模式。

## 阶段 2：Kiosk 部署

- 增加 Ubuntu 运行脚本。
- 增加 systemd 用户服务模板。
- 文档化 HDMI 第二显示器设置。

- 增加启动和异常重启行为。

## 阶段 3：组件 SDK

- 增加组件 manifest 校验。
- 增加组件生成脚本。
